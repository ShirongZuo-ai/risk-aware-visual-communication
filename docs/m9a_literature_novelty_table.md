## Current overlap assessment

Directly overlapping foundations already include task-dependent rate allocation for visual navigation, future-trajectory collision assessment, goal-oriented transmission for obstacle avoidance, risk-aware planning, and predictive image-space traversability. The project must not claim any of these broad ideas as new.

The narrower candidate contribution remains unconfirmed rather than novel:

> independently validated future ego-motion danger -> spatial allocation of transmitted robot-camera fidelity -> constrained-navigation safety.

The reviewed Pedram work already covers navigation-dependent information-rate allocation, while GOSC already covers prediction/VoI-driven transmission and obstacle-avoidance task success. A defensible distinction would require evidence that physical future-danger prediction is valid (M9), that it controls spatial visual resources rather than generic sensing/C&C slots, and that the resulting remote visual channel improves a preregistered safety task. None of those three together is yet established in this repository.

# Track-B closed-loop communication update (search cutoff 2026-08-13)

The closest adjacent work spans task-oriented visual coding, spatially selective collaborative perception, predictive attention, and communication-aware control. TAGIC jointly learns image communication and a driving task; Where2comm and When2com allocate collaborative-perception communication; predictive perceptual attention uses MPC to focus visual processing; RAST builds predicted risk corridors; recent predictive-latent UAV work co-adapts motion and transmission power. None alone establishes the narrower proposed experiment: predicted ego danger controlling both spatial and temporal visual fidelity, with actual matched bytes and closed-loop physical navigation outcomes.

Accordingly, the defensible prospective wording is: *we study whether predicted ego danger can serve as a common signal for where and when to spend a fixed visual-communication budget in closed-loop navigation*. Broad first-of-kind claims remain prohibited.
